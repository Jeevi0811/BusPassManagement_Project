# Bus Pass Management System

## Project Description
Bus Pass Management System is a Java console-based application developed to simplify the process of managing student bus passes. The system allows students to enter their details, automatically generates a unique bus pass number, calculates the bus fee based on the travel distance, and displays all the bus pass information in a structured format.

## Features
- Student ID Entry
- Auto Generate Bus Pass Number
- Student Name
- Mobile Number
- Department
- Year of Study
- Bus Route
- Distance Calculation
- Bus Fee Calculation
- Payment Mode (Cash / UPI / Card)
- Bus Pass Status (Approved)
- Issue Date
- Expiry Date
- Display Complete Student Details

## Technologies Used
- Java

## How to Run
1. Clone or download the project.
2. Open the project in VS Code.
3. Compile the program:
   ```
   javac BusPassManagement.java
   ```
4. Run the program:
   ```
   java BusPassManagement
   ```
